# SQ4+ 叶子完整距离复用

状态：实验开关保留。最初串行PUBLISH下完整构图未提速；消除发布瓶颈后，完整距离复用上三角已取得GPU和完整墙钟收益，见下文顺序对照。检索质量仍未验收；新叶子大小策略保持停用。

## 开关与范围

```bash
# 保留原融合叶子行为的当前速度基线：原叶子策略、投影复用、8×32 分区、CTA复制
export SHEAR_PIPNN_SQ8_WMMA_OPT_MASK=525824

# CTA复制 + 完整距离复用64×64上三角（速度验收通过，检索质量待验收）
export SHEAR_PIPNN_SQ8_WMMA_OPT_MASK=591360

# 再加16×16操作数复用（GPU收益已验证，微小墙钟收益仍接近波动）
export SHEAR_PIPNN_SQ8_WMMA_OPT_MASK=4785664

# 旧实验：64×64 上三角，只复用整数点积
export SHEAR_PIPNN_SQ8_WMMA_OPT_MASK=17920

# 历史对照：串行PUBLISH + 64×64完整距离复用（1536 + bit65536）
export SHEAR_PIPNN_SQ8_WMMA_OPT_MASK=67072
export SHEAR_PIPNN_SQ4_PRIMARY_TRIANGULAR=0
```

适用于385..1280点、k<=4、原生INT4旋转残差、无精算/分列的大叶子。其它情况沿用原叶子路径。bit65536自动选择已有64×64分块，不叠加目标叶子策略bit32768。

对每个有效无序点对，恢复一次完整距离，将其FP32位模式存入原共享tile；两个端点按原候选遍历顺序分别更新自己的top-k。更新候选集合仍需两次，但不再重复读取交叉投影/Gram并恢复距离。沿用16,640B动态共享区域，没有新增全局N×N矩阵；原生8×8 WMMA对角块内部的点积冗余保留。

## 数值约定

旧公式的两个交叉投影按端点顺序相加，因此交换端点后可能有FP32末位差异。新分支按全局点ID固定完整距离的求值方向，使同一无序点对共享同一分数，且不依赖分区内resident行号。分区距离公式未改变。

12,059,496个固定任务输出位置中，新版与采用相同方向、逐方向独立恢复的参考路径在邻居ID和分数字位上完全一致。相对旧公式有3个邻居位置变化，涉及2行：1个成员替换及另1行的两个邻居交换顺序。GPU逐点重算确认是末位舍入使候选分差跨越既有2e-5并列阈值。详见实验目录的 `numerical-diagnosis.json`。

不能把该实现描述为对旧有向公式逐位等价。当前仅做构图测试，没有Recall/QPS结论；采用默认配置前须单独评测质量。

## 叶子级归因补测

固定D0的LAION10M补测确认：385–512、513–768、769–1024、1025–1280点叶子的每叶累计CTA服务时间分别减少26.5%、27.8%、29.2%、28.6%，局部收益没有被完全抵消。统一计至CTA完成屏障之后；原`P_LEAF_SCORE_CLOCKS`在该屏障之前结束，不能替代完整叶子计时。

详细采样中，生产后/消费后的CTA同步约占上三角大叶子服务量的1.5%/24.8%。消费阶段仅部分warp持有当前64×64 tile涉及的行，其余warp等待。未插桩控制的墙钟47.445→47.920秒，GPU19.569→19.536秒，仍无端到端收益。轻量时间线显示全部分区完成后的尾部合计0.020→0.105秒，主要约束是任务发布/供给与调度：叶子CTA工作量640.7→518.3 CTA秒，调度/轮询/等待余项1528.2→1635.1 CTA秒；两版PUBLISH均约370亿周期。

本轮统一使用tmpfs输出，不能与历史磁盘输出直接比较墙钟；阶段采样有扰动，未取得硬件访存stall计数。协议、逐大小桶结果、采样开销、全部原始对照及局限见 [叶子级分析报告](../../runs/sq4_leaf_profile_20261107/report.md)。诊断本身不代表检索质量验收。

## 发布瓶颈修复后的顺序优化

PUBLISH原先由一个线程复制成员，阻塞后续任务供给。bit524288只把成员复制改为整个CTA协作，元数据预留、子节点遍历、种子和就绪发布次序保持原流程。每个writer先执行threadfence，CTA会合后owner再发布ready；固定任务另用并发reader验证发布可见性。

在原融合叶子上，ABBA的10M墙钟中位数47.605→40.190秒，GPU19.6165→10.854秒，PUBLISH累计周期减少79.5%。固定17种发布场景的成员、描述符、种子和非时钟计数逐位一致。后续保留原融合叶子行为的速度基线改为mask525824。

再固定更快的PUBLISH，仅切换完整距离复用上三角：墙钟40.380→39.875秒，GPU10.860→9.7945秒。说明叶子收益此前主要被任务供给瓶颈掩盖。mask591360已通过这一速度对照，但既有近并列数值差异及待验收的检索质量结论不变。两组计时各自使用成对轮次，不能混用不同轮次来计算单项收益。详见 [PUBLISH及叶子重测](../../runs/sq4_publish_copy_20261107/report.md)。

为减少同步次数，随后单独测试外层tile64/80/96。64/80/96的GPU中位数为9.8025/10.462/10.272秒，墙钟39.775/40.640/40.275秒，保留64。较大tile在独立叶子wrapper中有局部收益，但生产内核的共享资源需求上升，完整构图变慢。详见 [外层tile实验](../../runs/sq4_leaf_tile_size_20261107/report.md)。

最后保持64×64外层tile，只将四个原生8×8 INT4 WMMA点积组合成16×16操作数复用（bit4194304，mask4785664）。寄存器中的四个累加器依次写入已失效的A操作数暂存区，没有增加shared数组。571392个整数点积与CPU参考严格一致，2136168个邻居ID/FP32分数位置与原完整距离实现逐位一致。

ABBA后追加BA复测，三轮中位数GPU9.793→9.196秒（−6.1%），叶子评分累计周期−18.4%；分配距离和PUBLISH周期基本不变。墙钟40.060→39.780秒（−0.7%），范围仍重叠。内核准备与编码/结果等待抵消部分GPU收益。保留为已验证GPU收益的实验开关，不把这点墙钟差异认定为稳定端到端提速；检索数值约定仍沿用完整距离分支。完整范围、资源及重放见 [操作数复用实验](../../runs/sq4_leaf_operand_reuse_20261107/report.md)。

以上均为SQ4+内部对照，固定D0和原叶子策略、统一热缓存与tmpfs输出；每轮图通过结构审查，无CPU/队列回退。本轮没有执行100M或Recall/QPS。
