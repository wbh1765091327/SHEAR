# SQ4+ 目标叶子大小策略

状态：按用户 2026-11-07 决定暂停采用。LAION10M 已完成 A/B、B/A；小叶子显著减少，但叶内点对增加、完整构图变慢。后续 SQ4+ 优化恢复原叶子策略，以 mask1536 为基线，不再叠加 bit32768。实现和原始实验保留用于复现。

## 开关和适用范围

在当前一点一码 SQ4+、原生 INT4、fused-persistent 路径上：

```bash
# 当前推荐基线：交叉投影复用 + 8×32 分区，原融合叶子
export SHEAR_PIPNN_SQ8_WMMA_OPT_MASK=1536

# 已暂停的实验策略，仅用于重放历史实验：增加 bit 32768
export SHEAR_PIPNN_SQ8_WMMA_OPT_MASK=34304
```

新策略的 GPU 规划值为 soft_min=128、target=256，max 保持原配置（本轮 1280）。128 是当前 8 warp × 16 源点的任务粒度，不是硬件规定的最小叶子；大于 128 的叶子仍可能有尾任务。不要将这个开关加入普通 SQ8 标准基线。

## 实际行为

- 对允许重新选择 leaders 的节点，以 `ceil(N × fanout / 256)` 决定初始数量，限制在现有容量及 `floor(N × fanout / 128)` 内。可行时要求 leader 数量大于 fanout。保留上游提供的根层 leaders、原有采样方法和退化处理。
- 大节点 SCATTER 完成后，仅由取得发布锁的 CTA 整理同父节点的小子块。优先选择距离近且点数之和不超过上限的兄弟叶子，用 leader ID、slot 打破并列。
- CTA 协作排序、去重和搬运成员，使用 12 KiB 动态共享内存，以及已经完成用途的 assignment-slot 缓冲区。未合并的大子块保持原存储，不增加全局 N×N 矩阵或新的全局暂存分配。
- scalar 回退节点采用相同的 leader 数量规则和 128 合并阈值；其既有小块合并次序保持不变。
- 容量判断保守地使用两个块点数之和。输入不足、没有容量合适的兄弟块，或合并去重后重新低于 128 时，允许保留小叶子。大节点计数日志记录合并数、去重数和小叶子例外。共享排序容量限制单次合并结果不超过 `min(leaf_max,2048)`。
- D0、fanout、量化、原融合叶子计算和 max=1280 不变；分区与候选边集合会改变，不能按等价内核优化跳过质量验收。

## 后续上三角方向

当前实现只复用整数点积，两个端点仍分别恢复完整距离。后续目标是在原叶子策略上，对每个无序点对计算一次整数点积、恢复一次完整距离，再将同一分数分别送入两个端点的top-k。两套top-k状态和各自的比较更新不能省略，也不能直接把一个端点的入选结果镜像给另一个端点。

该方向已在原叶子策略上实现为独立实验bit65536，详见 [完整距离复用](sq4_leaf_shared_distance.md)。固定任务确认新版与同方向参考逐位一致；相对旧公式有已定位的近并列选边变化。数学对称不自动保证旧实现两个方向的FP32分数字位一致，仍保持实验配置。
